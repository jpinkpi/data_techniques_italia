Big Data Techniques – University of Genoa

This repository contains exercises, classwork, and analytical projects developed during the Big Data Techniques course at the University of Genoa (Università degli Studi di Genova) as part of my academic exchange in Italy.

The repository documents my practical introduction to data analysis, text processing, Natural Language Processing (NLP), and applied Python programming.
